# 室內地圖與導航系統

本模組提供校園建築的室內地圖展示與路徑規劃功能，讓學生能夠輕鬆找到教室位置並獲得最佳路線指引。

## 📱 功能概述

室內地圖與導航系統是一個完整的室內定位與路徑規劃解決方案，它利用校園建築平面圖與參考點資料庫，提供精確的室內位置資訊與路徑指引，幫助學生快速找到目的地。

## ✨ 主要特性

### 1. 多樓層地圖瀏覽
- **五層建築平面圖**：包含綜合教學大樓 1-5 樓完整平面圖
- **樓層切換**：便捷的樓層選擇欄，快速切換不同樓層
- **地圖操作**：支援縮放、平移等交互操作

### 2. 教室與地標顯示
- **視覺化標記**：所有教室與重要地點以彩色標記顯示
- **資訊顯示**：點擊標記可查看詳細資訊
- **關鍵點高亮**：重要地點可被高亮顯示

### 3. 路徑規劃與導航
- **起終點選擇**：支援通過地圖點擊或列表選擇設定起點和終點
- **最短路徑計算**：使用優化算法計算最短路徑
- **視覺化路徑**：清晰的路徑線條顯示
- **路徑資訊**：顯示距離等路徑相關資訊

### 4. 教室搜索功能
- **快速搜索**：支援教室名稱搜索
- **結果高亮**：搜索結果在地圖上高亮顯示
- **自動定位**：搜索後自動切換至目標所在樓層

### 5. 列表管理功能
- **教室列表**：顯示當前樓層所有教室
- **分類過濾**：可按樓層或其他條件過濾
- **互動操作**：點擊列表可在地圖上高亮對應地點

## 🔧 技術實現

### 核心技術
- **自定義地圖視圖**：基於 TouchImageView 擴展的自定義 MyCustomImageView 類
- **Jetpack Compose UI**：使用現代化的 Compose 構建用戶界面
- **Canvas 繪圖**：使用 Android Canvas API 實現路徑和點位繪製
- **觸控事件處理**：實現平滑的地圖交互體驗
- **GSON 數據處理**：使用 GSON 解析 JSON 格式的教室數據

### 關鍵數據模型
- **ReferencePoint**：表示地圖上的參考點，包含位置坐標與屬性
- **MapImage**：地圖圖像資源信息
- **NavigationPath**：導航路徑信息，包含點位序列與距離
- **CurrentPosition**：當前位置信息

## 📋 使用指南

### 基本瀏覽
1. 選擇樓層：點擊頂部的樓層標籤切換不同樓層
2. 瀏覽地圖：使用標準觸控手勢放大、縮小和平移地圖
3. 查看教室：點擊地圖上的彩色標記或底部列表查看教室信息

### 搜索教室
1. 點擊頂部搜索欄
2. 輸入教室編號或名稱（如 "sec101"）
3. 按下搜索按鈕或鍵盤上的搜索鍵
4. 系統自動切換到對應樓層並高亮顯示目標教室

### 路徑導航
1. 點擊右上角的導航圖標進入導航模式
2. 設置起點：點擊地圖上的某個地點或從列表中選擇
3. 設置終點：再次點擊地圖或從列表中選擇
4. 點擊「計算路徑」按鈕生成導航路線
5. 查看高亮顯示的最短路徑和距離信息

## 🗂️ 數據來源

室內地圖系統使用 `classroom_points.json` 文件存儲所有參考點數據。此數據包括：
- 教室編號和名稱
- 教室坐標（使用百分比坐標系統，與圖像尺寸無關）
- 所屬樓層信息

## 🔍 開發示例

### 新增自定義參考點
```kotlin
val newPoint = ReferencePoint.createSimplePoint(
    name = "自習室",
    x = 50.0,  // X 坐標（百分比）
    y = 50.0,  // Y 坐標（百分比）
    imageId = R.drawable.se1,  // 樓層圖片資源ID
    scanCount = 0
)
allReferencePoints += newPoint
```

### 計算兩點之間的路徑
```kotlin
val startPoint = /* 獲取起始參考點 */
val endPoint = /* 獲取目標參考點 */
val path = findPath(allReferencePoints, startPoint, endPoint)
// 顯示路徑
customImageView.navigationPath = path
customImageView.startPoint = startPoint
customImageView.endPoint = endPoint
customImageView.invalidate()
```
