# 室內地圖與導航系統

本模組提供校園建築的室內地圖展示與路徑規劃功能，讓學生能夠輕鬆找到教室位置並獲得最佳路線指引。

## 📱 功能概述

室內地圖與導航系統是一個完整的室內定位與路徑規劃解決方案，它利用校園建築平面圖與參考點資料庫，提供精確的室內位置資訊與路徑指引，幫助學生快速找到目的地。

## ✨ 主要特性

### 1. 多樓層地圖瀏覽
- **五層建築平面圖**：包含綜合教學大樓 1-5 樓完整平面圖
- **樓層切換**：便捷的樓層選擇欄，快速切換不同樓層
- **地圖操作**：支援縮放、平移等交互操作

### 2. 教室與地標顯示
- **視覺化標記**：所有教室與重要地點以彩色標記顯示
- **資訊顯示**：點擊標記可查看詳細資訊
- **關鍵點高亮**：重要地點可被高亮顯示

### 3. 路徑規劃與導航
- **起終點選擇**：支援通過地圖點擊或列表選擇設定起點和終點
- **最短路徑計算**：使用優化算法計算最短路徑
- **視覺化路徑**：清晰的路徑線條顯示
- **路徑資訊**：顯示距離等路徑相關資訊

### 4. 教室搜索功能
- **快速搜索**：支援教室名稱搜索
- **結果高亮**：搜索結果在地圖上高亮顯示
- **自動定位**：搜索後自動切換至目標所在樓層

### 5. 列表管理功能
- **教室列表**：顯示當前樓層所有教室
- **分類過濾**：可按樓層或其他條件過濾
- **互動操作**：點擊列表可在地圖上高亮對應地點

## 🔗 室外室內整合導航

### 自動轉換機制
- **SE系列教室導航**：當用戶搜尋 SEC 或 SE 開頭的教室時，系統自動導航到理工學院
- **到達提醒**：當用戶接近理工學院（50公尺內）時，自動提示進入室內地圖
- **無縫切換**：從室外地圖可直接切換到室內地圖，並保持目的地設定

### 預設起點設定
- **入口位置**：室內地圖預設起點設為理工學院入口（1樓：x=36.21%, y=68.26%）
- **自動規劃**：從室外進入時自動規劃從入口到目標教室的路線
- **位置標示**：清楚標示當前位置為理工學院入口

### 新功能：室內路線快速查看
- **室內路線按鈕**：在室外地圖規劃到理工學院或SE系列教室時，顯示「看室內路線」按鈕
- **一鍵切換**：點擊按鈕可直接跳轉到室內地圖並保持目標設定
- **智能判斷**：系統自動判斷目的地是否支援室內導航功能
- **目標保持**：從室外搜尋的SE系列教室會自動傳遞到室內地圖

### 使用流程
1. 在室外地圖搜尋 SE 系列教室（如 "sec101"）或選擇「理工學院」
2. 系統自動規劃室外路線並顯示「看室內路線」按鈕
3. 點擊「看室內路線」可立即查看建築內部路線
4. 或選擇按照室外路線導航，到達時會自動提示進入室內地圖
5. 室內地圖會自動從入口規劃到目標教室的路線

## 🔧 技術實現

### 核心技術
- **自定義地圖視圖**：基於 TouchImageView 擴展的自定義 MyCustomImageView 類
- **Jetpack Compose UI**：使用現代化的 Compose 構建用戶界面
- **Canvas 繪圖**：使用 Android Canvas API 實現路徑和點位繪製
- **觸控事件處理**：實現平滑的地圖交互體驗
- **Room 資料庫**：使用 Room 持久化庫管理教室和建築資料

### 關鍵數據模型
- **ReferencePoint**：表示地圖上的參考點，包含位置坐標與屬性
- **BuildingEntity**：建築物實體，包含建築資訊和入口位置
- **FloorEntity**：樓層實體，包含樓層資訊和對應圖片
- **CorridorVectorEntity**：走廊向量實體，定義走廊的起終點
- **AreaConnectivityEntity**：區域連通性實體，定義可通行區域

## 📋 使用指南

### 基本瀏覽
1. 選擇樓層：點擊頂部的樓層標籤切換不同樓層
2. 瀏覽地圖：使用標準觸控手勢放大、縮小和平移地圖
3. 查看教室：點擊地圖上的彩色標記或底部列表查看教室信息

### 搜索教室
1. 點擊頂部搜索欄
2. 輸入教室編號或名稱（如 "sec101"）
3. 按下搜索按鈕或鍵盤上的搜索鍵
4. 系統自動切換到對應樓層並高亮顯示目標教室

### 路徑導航
1. 點擊右上角的導航圖標進入導航模式
2. 設置起點：點擊地圖上的某個地點或從列表中選擇
3. 設置終點：再次點擊地圖或從列表中選擇
4. 點擊「計算路徑」按鈕生成導航路線
5. 查看高亮顯示的最短路徑和距離信息

## 🗂️ 數據來源

室內地圖系統現在使用 **Room 資料庫** 存儲所有參考點數據。資料庫包括：

### 資料庫架構
- **buildings**：建築物資訊表
  - 建築物 ID、名稱、描述
  - 入口座標和樓層資訊
  
- **floors**：樓層資訊表
  - 樓層編號、名稱
  - 對應的圖片資源 ID
  
- **reference_points**：參考點資訊表
  - 教室編號和名稱
  - 教室坐標（使用百分比坐標系統）
  - 點位類型（教室、走廊、樓梯等）
  - 所屬建築物和樓層資訊
  
- **corridor_vectors**：走廊向量表
  - 走廊的起始和終點座標
  - 走廊標識和描述
  
- **area_connectivity**：區域連通性表
  - 可通行區域的邊界座標
  - 連接的走廊資訊

### 資料管理
- **自動初始化**：首次啟動時自動載入預設的教室和設施資料
- **動態更新**：支援即時新增、修改和刪除參考點
- **資料持久化**：所有變更自動保存到本地資料庫
- **搜尋功能**：支援快速搜尋和過濾功能

## 🔍 開發示例

### 新增自定義參考點
```kotlin
// 使用 ViewModel 新增參考點
val newPoint = ReferencePoint.createSimplePoint(
    name = "自習室",
    x = 50.0,  // X 坐標（百分比）
    y = 50.0,  // Y 坐標（百分比）
    imageId = R.drawable.se1,  // 樓層圖片資源ID
    type = PointType.OTHER

viewModel.addReferencePoint(newPoint)
```

## 📐 系統架構

該系統採用現代化的 MVVM 架構設計，主要包含：
- **UI 層**：使用 Jetpack Compose 構建的響應式用戶介面
- **ViewModel 層**：管理 UI 狀態和業務邏輯
- **Repository 層**：統一的資料存取介面
- **Database 層**：使用 Room 的本地資料庫
- **View 層**：自定義的地圖視圖元件，處理觸控互動和繪圖

## 🔄 主要改進

1. **資料庫管理**：從 JSON 文件改為 Room 資料庫，提供更好的資料持久化和查詢功能
2. **架構優化**：採用 MVVM 架構，提高代碼的可維護性和可測試性
3. **動態資料**：支援即時新增、修改和刪除參考點，無需重啟應用
4. **效能提升**：使用 Flow 進行響應式資料處理，提供更流暢的使用體驗
5. **擴展性**：新增建築物、樓層、走廊向量等實體，支援更複雜的室內地圖功能
6. **資料完整性**：使用外鍵約束確保資料一致性
7. **搜尋功能**：提供強大的搜尋和過濾功能
8. **預設資料**：自動載入理工學院的完整建築和教室資料
