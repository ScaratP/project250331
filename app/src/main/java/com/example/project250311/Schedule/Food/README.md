# Food (學餐轉盤模組)

## 📌 簡介
此模組提供一個互動式的「學餐轉盤」功能，旨在解決學生日常「今天吃什麼？」的選擇困難症。系統內建臺東大學理工學院及周邊的餐飲資訊，透過轉盤隨機抽選，增加用餐的趣味性。同時具備智慧篩選功能，能根據當前時間與星期，自動過濾掉未營業的店家。

## ✨ 功能特色
* **互動式轉盤**：
    * 支援 **手勢拖曳**：使用者可以像撥動真實轉盤一樣，透過滑動螢幕來轉動轉盤。
    * **慣性物理**：轉動具有加速度與減速效果，模擬真實物理回饋。
    * **一鍵隨機**：提供按鈕直接進行隨機快速旋轉。
* **智慧營業判斷**：
    * **時段過濾**：自動識別當前是早餐、午餐或晚餐時段，僅顯示該時段有營業的店家。
    * **即時狀態**：在列表中標示店家目前是「營業中」還是「休息中」。
    * **排除公休**：自動過濾掉非營業日（如週末公休）的選項。
* **店家資訊整合**：
    * 抽選結果顯示詳細資訊（位置、描述）。
    * **一鍵撥號**：直接點擊按鈕撥打店家電話訂餐。
    * **網站連結**：支援跳轉至店家社群網站或線上點餐系統。
* **客製化管理**：使用者可手動勾選/隱藏特定店家，自訂轉盤上的選項。

## 📂 檔案結構與職責

本資料夾 (`Food/`) 目前包含核心邏輯與 UI：

* **`FoodScreen.kt`**
    * **UI Composable**:
        * `FoodScreen`: 主畫面容器，包含標題、轉盤區域、結果卡片與店家列表。
        * `drawFoodWheel`: 使用 `Canvas` 繪製扇形、文字與陰影，實現客製化轉盤視覺。
    * **資料結構**:
        * `FoodOption`: 定義店家屬性（名稱、顏色、電話、營業時間表）。
        * `OperationSchedule` / `WeekDay` / `OperationTime`: 精細的營業時間模型。
    * **核心邏輯**:
        * `isOpenNow`: 判斷店家當下是否營業的核心演算法。
        * `calculateSelectedFood`: 根據轉盤停止的角度計算指針指向的店家。
        * `spinWheel` / `manualSpin`: 處理旋轉動畫與角度計算。

## 🛠️ 技術實作細節

### 1. Canvas 繪圖與幾何計算
轉盤並非使用現成圖片，而是透過 Compose `Canvas` 動態繪製：
* 使用 `drawArc` 繪製扇形，並根據店家是否營業調整顏色透明度（營業中較鮮豔，休息中較黯淡）。
* 使用 `rotate` 與三角函數 (`sin`, `cos`) 計算文字標籤的正確角度與位置。

### 2. 手勢偵測 (Gesture Detection)
使用 `pointerInput` 與 `detectDragGestures` 實作拖曳互動：
* 計算手指觸碰點與圓心的夾角變化 (`atan2`) 來決定轉動方向與速度。
* 處理角度跨越 0 度/360 度的邊界情況，確保旋轉流暢。

### 3. 營業時間邏輯
系統將一天分為三個時段：
* **早餐 (Morning)**: 06:00 - 11:00
* **午餐 (Afternoon)**: 11:00 - 17:00
* **晚餐 (Evening)**: 17:00 - 23:00

系統會比對 `FoodOption` 中的 `openDays` (星期幾) 與 `operationSchedules` (時段)，決定該店家是否顯示於轉盤上。
